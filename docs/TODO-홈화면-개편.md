# 홈 화면 개편 (예정)

> 2026-09-19 Min 요청. **아직 적용 안 함** — 나중에 세팅할 것.

앱을 처음 열었을 때 보이는 순서를 바꾼다.

## 1. 맨 위: 사장님 지시사항

홈 최상단에 새 카드 하나. 제목은 `사장님 지시사항`, 내용은 불릿 목록.

```
사장님 지시사항
· 지시 내용 한 줄
· 지시 내용 한 줄
· 지시 내용 한 줄
```

- 매출 카드보다 **위**에 온다
- 입력은 admin 에서 (등록 화면 · 저장 위치 미정)
- 비어 있을 때 어떻게 할지 미정 (카드를 숨길지, 빈 문구를 둘지)

## 2. 그 밑: 매출 — 사업부별로

지금은 전사 한 덩어리(실적/타겟 + 막대 하나)다. 이걸 **사업부마다 한 줄**로 바꾼다.
맨 위에는 총합을 그대로 두고, 그 아래에 사업부별 막대가 줄줄이 온다.

```
9월 매출                                    사업부별
$676만 / $2,500만                              27%
실적 / 타겟 · 남은 타겟 $1,824만
[======                                  ]
────────────────────────────────────────
반도체사업부                     $676만 / $2,500만
[======                            ]     27%
자동차사업부                              미등록
[                                  ]
   …
```

- 줄 순서는 진행현황과 같이 divisions.json 의 order
- **문제**: 지금 `revenue.json` 은 반도체 기준 한 덩어리라 사업부별로 못 쪼갠다.
  사업부별 실적/타겟을 admin 에서 따로 받아야 한다. 그때까진 나머지는 '미등록'
- 실적이 아니라 예상으로 볼지, 타겟 대비로 볼지 확정 필요 (지금 시안은 실적/타겟)

## 3. 전체 현황 → 사업부별 진행현황

지금은 프로젝트 전체를 뭉쳐서 `정상 / 일정 지연 / 특이사항 / 집중관리` 네 칸으로
보여준다. 이걸 **사업부마다 한 줄씩** 나오는 목록으로 바꾼다.

```
사업부별 진행현황

· 반도체사업부    정상 00건   지연 00건   특이사항 00건   집중관리 00건
· 자동차사업부    정상 00건   지연 00건   특이사항 00건   집중관리 00건
· 아리스타       정상 00건   지연 00건   특이사항 00건   집중관리 00건
   …
```

- 줄 순서는 `backend/config/divisions.json` 의 order 를 따른다
  (반도체 · 아리스타 · 블룸 · ESS · PCB · 자동차 · 네트워크 · 시스템 · 자동화)
- 집계 기준은 지금 쓰는 것과 같아야 한다 —
  전체 = 정상 + 지연 + 특이사항 + 집중관리 (보류는 집중관리에 포함)
- 한 줄을 누르면 그 사업부 화면으로
- 프로젝트가 없는 사업부를 숨길지 여부 미정

## 정해야 할 것

- [ ] 프로젝트 0개인 사업부를 목록에서 뺄지
